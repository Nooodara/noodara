---
title: Service
description: One deployable application, built from a Git repository, a Dockerfile or an image.
---

A Service is one deployable application. It runs on a Server, inside an Environment, and is built
from exactly one source: a Git repository, a Dockerfile, or a pre-built image.

Each Service can carry its own domains, environment variables and secrets, layered on top of
whatever its Environment and Project already define.

Deploy a Service from its page; see the first deploy guide for the steps.
