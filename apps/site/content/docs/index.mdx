Noodara connects to a server you already own over SSH, discovers what is running on it, and
gives you a clear picture of your infrastructure. No agent installed on the target server, no
black box.

These docs are organized into four groups.

## Getting started

Install Noodara on an Ubuntu server, sign in for the first time, and add your first server.
Start with [Install](/docs/getting-started/install).

## Concepts

The model behind Noodara: servers, projects, environments, services and deployments, and how
they relate to each other. Start with [Server](/docs/concepts/server).

## Operate

Day-to-day operation: upgrading, rolling back, backing up, and diagnosing a failed install.
Start with [Upgrade](/docs/operate/upgrade).

## Reference

Supported environment variables, exit codes, error codes, and exactly what this release
includes. Start with [Scope of this release](/docs/reference/scope).
