# Noodara v0.3 — Matriz de integración (roadmap §8.8)

Cada escenario de §8.8 apunta a un test nombrado que corre una vez por versión de Ubuntu
(`describe.each(DEPLOY_ENGINE_UBUNTU_VERSIONS)`, sshd + dockerd reales). Con `NOODARA_TEST_UBUNTU=all`
(main y nightly) corre en 22.04 y 24.04.

`tests/unit/deploy-engine/scenario-map.test.ts` (datos en `tests/integration/deploy-engine/scenario-map.ts`) verifica esta tabla: falla si falta un escenario,
si el nombre del test no existe, si está saltado (`.skip`, `.todo`, `.skipIf`, `.runIf`, `context.skip()`,
`return` según la versión) o si no corre en alguna de las dos versiones.
