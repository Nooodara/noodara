## Política de build cache (D12, ADR 0009)

Tras un deployment `SUCCESS`, el worker corre `docker builder prune --force --filter until=168h` (sin `--all`): solo
cache sin uso por 7 días. Máximo una vez por servidor cada 24 h (clave Redis `noodara:build-cache-prune:<serverId>`, `SET NX EX 86400`),
nunca mientras otro deployment del servidor está `BUILDING`, timeout duro de 120 s; un fallo o timeout libera la clave y
el resultado jamás cambia el deployment ni se registra. Se desactiva con `NOODARA_BUILD_CACHE_PRUNE=off`.
Evidencia: `build-cache-prune.test.ts` (unit, dentro de 04) y `runtime-pipeline` 14-10 A3 (un prune para dos deployments,
contenedor e imagen intactos; 08).
