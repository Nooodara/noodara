## Host y adaptaciones

- VM Lima `noodara-uat`, Ubuntu 24.04 LTS, aarch64, 4 vCPU, 4 GiB. Usuario SSH `paas` (no-root, sudo, grupo `docker`, solo
  llave). `v0.3.0` instalado con el instalador público; puerto 3000 reenviado al Mac. Los pasos de panel se hicieron con la
  misma API HTTP que usa el panel (sesión, `Origin` = `NOODARA_PUBLIC_URL`).
- CA: Pebble 2.10.1 en el host (red Docker `uat-acme`, alias `pebble`, `-dnsserver 8.8.8.8`, validez 90 días). Seam ACME
  del control plane: `NOODARA_ACME_CA_URL=https://pebble:14000/dir` y `NOODARA_ACME_CA_ROOT_FILE` en `.env` más el override de
  compose `/opt/uat-pebble/uat-pebble.yml` (se reaplica tras cada corrida del instalador). Evidencia: `u06-acme-seam.txt`.
- Dominio: `app.<vm-ip>.sslip.io` (sslip.io resuelve a la IP privada de la VM). "Hosts override" = `curl --resolve` hacia
  la VM; HTTPS se verifica contra la raíz de Pebble (`verify=0`).
- La VM es la propia máquina gestionada: el control plane se conecta a ella por su IP privada.
