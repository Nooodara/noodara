| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-25 | Tampering | sync script | mitigate | Frozen allowlist of 7 dest names; no delete API; paths from `import.meta.dirname`; unit test proves foreign files untouched and non-allowlisted names never written |
| T-07-26 | Tampering | served SVG favicon | mitigate | Byte-equal to `packages/ui/brand/favicon.svg`, which 07-06's test proves script-free; Next serves it as `image/svg+xml` via the file convention |

| T-07-SC | Tampering | npm installs | accept (n/a) | None |
