| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-03 | Elevation of Privilege | native binary in `sharp` | accept | Build-time only, never in the request path; CI runs it inside the unit job with no secrets in env beyond fake fixtures; `pnpm audit --audit-level=high` already in the security job |
| T-07-04 | Tampering | `writeIfChanged` | mitigate | No `rm`/`unlink` API exposed; callers pass absolute paths they computed from `import.meta.dirname`, never from argv or env; ledger printed at the end of every run |
| T-07-05 | Information Disclosure | Playwright fallback rasterizer | mitigate | `page.setContent` with a code-authored SVG only; no navigation to any URL; no cookies; headless |
