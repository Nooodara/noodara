## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user input (API, Phase 12) -> domain validators | repository URL, branch, image ref, paths typed by an operator reach a remote shell later |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-03 | Tampering (command injection) | validateRepositoryUrl, validateGitBranch, validateImageRef, path validators | high | mitigate | Metacharacter/whitespace checks first, closed character classes per shape, named codes; Tasks 1-2 acceptance criteria assert newline, metachar and scheme rejections. Defense in depth: 11-13 still escapes every token |
| T-11-04 | Tampering (argument injection) | host/path/branch/tag beginning with '-' | high | mitigate | Leading '-' rejected in host, user, path segments, branch, image ref and registry username (Tasks 1-2 behaviors); 11-13 additionally places `--` before positionals |
| T-11-05 | Information Disclosure | https URLs with userinfo | high | mitigate | REPOSITORY_URL_EMBEDDED_CREDENTIALS rejects any userinfo on https and user:password on ssh (Task 1), so a token can never be stored in or passed via the URL (ROADMAP D6/D7) |
| T-11-06 | Elevation of Privilege (SSRF-like pivot) | repository host | medium | mitigate | D-06 rejects localhost, *.localhost, loopback/private/link-local/CGNAT literals syntactically (Task 1); DNS rebinding is out of scope because the clone runs on the user's own server |
</threat_model>
