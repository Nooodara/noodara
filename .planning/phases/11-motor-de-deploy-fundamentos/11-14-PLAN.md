|----------|-------------|

| control plane cancel -> remote process tree | cancellation must actually stop remote work |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-39 | Information Disclosure (secret in streamed log) | execStreaming | high | mitigate | Line-buffered per-line redaction, multi-line secret registration, split-secret tests (Task 1) and a real canary build (Task 3) |
| T-11-40 | Denial of Service (unbounded output / hung command) | execStreaming | high | mitigate | maxLineBytes, maxTotalBytes, maxDurationMs, idleTimeoutMs all mandatory options (Task 1) |
| T-11-41 | Denial of Service (orphan remote process after cancel) | killSupervisedOperation | high | mitigate | D-04 combined sequence, confirmed only on ps absence; proven on both versions (Tasks 2-3) |
| T-11-42 | Information Disclosure (stdin secret echoed in errors) | stdin path | high | mitigate | Plaintext written once to the channel, never stored in result/tails/errors (Task 1 behavior) |
| T-11-43 | Tampering (arbitrary command via stream API) | SshDeploySession.stream | high | mitigate | stream accepts only RemoteCommand (module-private brand) and renders via renderRemoteCommand; builders and scripts stay unexported (Task 2 acceptance) |
