<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Contributor pull request → main branch | CI is the only thing between an untested or secret-leaking change and the default branch |
| Dependency updates → lockfile | A transitive vulnerability or a swapped package enters here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-50 | Information Disclosure | Committed secrets | mitigate | gitleaks runs on every pull-request diff and over the whole tree on pushes to main, with a path-scoped allowlist only, so a broad regex cannot silently hide a real key (QA-01) |
| T-1-51 | Tampering | Vulnerable or substituted dependencies | mitigate | `pnpm audit --audit-level=high` blocks the merge, and `pnpm install --frozen-lockfile` prevents CI from resolving a different tree than the lockfile records (T-1-SC follow-through from Plan 01-01) |
| T-1-52 | Tampering | Coverage or purity regressions | mitigate | The `unit` job enforces the Vitest 95% thresholds for `packages/domain` and the `boundaries` job enforces the Turborepo import rule, so neither can be eroded silently (QA-02, RESEARCH Pitfall 4) |
| T-1-53 | Repudiation | A green pipeline that verifies nothing | mitigate | No `continue-on-error` on any required job, no `e2e` placeholder job, and an explicit check that Testcontainers actually ran by asserting no labelled containers survive |
</threat_model>
