<objective>
Stand up `apps/control-plane` as a Fastify service that cannot boot on a misconfigured VPS, and resolve the one packaging question the research left open.

INST-06 is the requirement that keeps Noodara out of the Dokploy CVE-2026-45631 class of failure (hardcoded fallback secret, CVSS 10.0). This plan makes "no defaults" structural: one Zod schema, parsed once, imported at the top of the entrypoint, with a lint rule from Plan 02 already banning the `??` fallback pattern in source.

Purpose: every later plan in this phase imports `env` and the Fastify app instance from here.
Output: control-plane package skeleton, `env.ts`, redacting logger, master-key boot warning, health route, and stub route plugins that later plans own exclusively.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| VPS operator `.env` → control-plane process | Misconfiguration here is the difference between encrypted credentials and a CVSS-10 default key |
| control-plane process → stdout / `docker compose logs` | Anything logged is readable by anyone with shell access to the host and by any future log shipper |
| HTTP client → Fastify routes | Untrusted request bodies and headers cross here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-04 | Elevation of Privilege | `apps/control-plane/src/env.ts` | mitigate | Zod schema with zero `.default()` on `NOODARA_MASTER_KEY`, `BETTER_AUTH_SECRET`, `DATABASE_URL`, `REDIS_URL`; placeholder values (`changeme`, `secret`, `password`, `noodara`, DB password `postgres`) are rejected; process exits 1 before Fastify listens (INST-06, D-09, PITFALLS.md #1) |
| T-1-05 | Information Disclosure | `apps/control-plane/src/logger.ts`, boot logging | mitigate | pino `redact.paths` covering cookie/authorization/password/credential paths with `[REDACTED]` censor; canary test asserts the master key and a private-key body never reach the emitted stream (Coolify #7019/#6658 pattern) |
| T-1-06 | Information Disclosure | Env failure report on stderr | mitigate | `EnvIssue` has no `received` field; a test asserts the rejected value is absent from the failure text, so a bad secret is not leaked into CI logs |
</threat_model>
