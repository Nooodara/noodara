<interfaces>
Tailwind v4 custom variant grammar (verified via Context7 /tailwindlabs/tailwindcss.com):
- Block form: `@custom-variant name { &:where(<selector>) { @slot; } }`
- Nesting media inside a block variant: `@custom-variant any-hover { @media (any-hover: hover) { &:hover { @slot; } } }`
- Overriding a built-in variant name (e.g. `dark`) with `@custom-variant` is the documented way to change its condition.
UNVERIFIED in this repo: multiple `@slot` rules inside one block variant (needed for OR). Task 1 step 1 spikes it.

Sheet.tsx today: `import { ..., useReducedMotion, ... } from 'motion/react'`; `const prefersReducedMotion = useReducedMotion();`; `drag={prefersReducedMotion === true ? false : 'x'}`.
