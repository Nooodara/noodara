<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser cookie → Next SSR → HTML | The client-controlled `noodara-prefs` value influences server-rendered markup |
| page script → document.cookie | A non-HttpOnly cookie is readable by any script on the origin |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-06 | Tampering (HTML injection) | layout.tsx attribute rendering | medium | mitigate | Task 2: only `preferencesToRootAttributes(parsePreferencesCookieValue(v))` output is rendered, which is enum-only; the E2E asserts a tampered value is not echoed |
| T-09-23 | Information disclosure | non-HttpOnly noodara-prefs | low | accept | D-09: the cookie carries only three enum tokens and no identity, session or secret. Documented in the ThemeToggle.tsx header |
| T-09-24 | Tampering (script injection) | THEME_BOOTSTRAP_SCRIPT | medium | mitigate | Task 2: it remains a compile-time constant with zero interpolation (grep gate), and is still the single dangerouslySetInnerHTML |
| T-09-25 | Tampering (second write path, P17) | any other DOM or cookie writer | medium | mitigate | Task 1 grep gate: no setAttribute('data-theme'/'data-motion'/'data-density') outside ThemeToggle.tsx |
</threat_model>
