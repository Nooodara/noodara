Never call `connectAndDiscover` here. Wrap the whole listener body in a try/catch that logs at error — an unhandled rejection inside an event listener would take the process down.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Redis → worker process | Job data read from Redis drives real SSH connections against real servers |
| worker process → remote server | The worker holds decrypted credentials in memory for the duration of a connect |
| worker lifecycle → persisted state | A crash mid-job leaves state that must be resolved, not trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
