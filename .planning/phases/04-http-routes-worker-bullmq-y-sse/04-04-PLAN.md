<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| exception → HTTP response | Internal error text, stack frames and driver messages reach an attacker-visible body |
| anonymous client → `/api/*` | Unauthenticated requests reach route handlers unless a scope guard stops them |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-04 | Information Disclosure | `app.setErrorHandler` | mitigate | Branch 3 returns a fixed `{ error: 'INTERNAL_ERROR', message: 'Internal error' }` and logs `appRedactor.redact(error.message)` with the request id; a canary test asserts the secret appears in neither body nor log |
| T-4-20 | Information Disclosure | Zod validation errors | mitigate | `toValidationErrorBody` copies only `path` and `message`, so a rejected credential value in a Zod issue's `received` field can never be echoed back |
| T-4-21 | Denial of Service | unhandled exception | mitigate | The error handler converts every throw into a response; an integration test asserts `/health` still answers 200 after a route throws (roadmap criterion 4) |
| T-4-01 | Spoofing | `/api/sessions` and every future guarded route | mitigate | `api-scope.ts` registers `requireSession` inside an encapsulated Fastify context; `/health`, `/api/auth/*`, `/api/setup`, `/api/recovery` stay siblings outside it, asserted by the guarded/unguarded matrix test |
| T-4-07 | Spoofing / CSRF | `DELETE /api/sessions*` | mitigate | `createOriginGuard(env.NOODARA_PUBLIC_URL)` registered as the scope's `onRequest` hook; asserted for both the mutation-rejected and GET-allowed cases |
| T-4-22 | Information Disclosure | response serialization failure | mitigate | `isResponseSerializationError` is handled as a 500 server bug rather than surfacing the offending payload to the client |
</threat_model>
