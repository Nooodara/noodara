## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| build output → public CDN | Whatever lands in apps/site/out is published verbatim |
| visitor browser → third parties | Any third-party asset leaks visitor IP/referrer |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-05 | Information disclosure (privacy) | exported HTML/CSS | medium | mitigate | check-export fails the build on any non-site asset origin or @font-face (D-14/D-16) |
| T-10-03 | Information disclosure | exported artifact | high | mitigate | findLeakedEnvNames blocks control-plane secret assignments in the export; the site build reads no secret env |
| T-10-21 | Tampering | wrong base path in production | low | mitigate | findBasePathMismatch + required CNAME file when public/CNAME exists (D-12, Pitfall 4) |
