## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server-supplied host key → rendered text | A value observed from a remote host is displayed to the operator for a trust decision |
| operator decision → stored trust | The dialog's confirmation changes which host key the system trusts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | `Fingerprint` | mitigate | Props accept a hash string only; the component holds no credential path, no `dangerouslySetInnerHTML`, and `CopyButton` copies the literal value it was given — `check:ui-safety`'s existing gates plus task 1's criteria enforce it |
| T-08-45 | Spoofing | host-key diff presentation | mitigate | The diff is block-aligned and marked by weight, so a single changed character is visible; marking by colour alone is forbidden (§9 #14) and asserted by a zero-colour-utility grep |

| T-08-47 | Tampering | rendering raw server text | mitigate | Only the fingerprint string is rendered, through React's text escaping; no server-supplied error text is rendered raw (§9 #17) |
| T-08-02 | Information Disclosure | approval captures of this screen | mitigate | Fixture host keys only; the `docs/ui/` credential scan from plan 08-01 covers every committed capture |
