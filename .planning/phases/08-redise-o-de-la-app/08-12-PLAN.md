<objective>
Make the `Sheet` draggable to dismiss with the full brief §7.4 sequence, using `motion` scoped so tightly that misuse elsewhere fails loudly. This is the component where the product's fluidity is judged (brief §7.4's own framing), and it is the only place in the codebase a JS animation library is allowed to exist.

Purpose: UI-06 and D19. Research resolved two real gaps — `domAnimation` has no drag, and Motion's velocity units and elastic constant are not guaranteed to match the brief's numbers — so the plan treats the brief's constants as calibration starting points with tests that measure rendered behaviour.
Output: `motion@13.4.1` registered and installed, `motion-tokens.ts`, `motion-features.js`, a draggable `Sheet`, and an E2E drag suite.
</objective>
