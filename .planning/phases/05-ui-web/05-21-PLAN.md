| credential material → every output surface | The union of backend surfaces (bodies, frames, logs, jsonb columns) and browser surfaces (DOM, console, storage, URL, history) |
| enforced rule → convention | A rule only checked by review erodes; a rule checked by a command does not |
| phase gate → next milestone | An unhonest gate carries defects into Phase 6's installer work |
