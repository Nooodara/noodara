## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local filesystem → browser memory → API request body | A private key crosses from disk into a form field; any detour through a URL, storage or a log is a credential leak |
| user keystrokes → destructive action | A weak confirmation gate turns a misclick into an irreversible delete or a trusted impostor host key |
| Radix primitive behaviour → custom overrides | Overriding focus trap or Esc would silently remove accessibility the product depends on |
