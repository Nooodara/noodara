<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `localStorage` → `data-theme` | An untrusted stored value reaching a DOM attribute |
| row activation → navigation | A row that navigates when the user meant to open its menu is a destructive-action risk once Delete lives in that menu |
| collapsed content → the accessibility tree | Content that is visually hidden but present would leak into screen-reader output and into DOM-scanning canary tests |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-38 | Tampering | `ThemeToggle` writing `data-theme` | mitigate | Only `light`/`dark` are ever written, asserted across the full cycle in a component test; `localStorage` access is try/catch-guarded and the throwing-storage case is tested |
| T-5-45 | Elevation of Privilege | a trailing-slot click activating the row instead of opening the menu | mitigate | The trailing slot is rendered outside the activation element and a component test clicks it and asserts `onActivate` was not called — this matters because Delete lives in that menu (Plan 05-17) |
| T-5-46 | Information Disclosure | collapsed content present in the DOM | mitigate | `Disclosure` uses the primitive's unmount-while-collapsed behaviour and a test asserts the content text is absent, which also keeps Plan 05-21's DOM canary scan honest |
| T-5-40 | Accessibility failure | unlabelled icon-only controls | mitigate | Component tests assert a real accessible name on the `RowMenu` trigger and on `ThemeToggle`, and a ≥44px hit area on the menu trigger |
| T-5-SC | Tampering | npm installs | mitigate | No new packages: all Radix primitives were installed and provenance-checked in Plan 05-08 |
