<objective>
Build the field-level half of the design system test-first: `Field`, `Input`, `Textarea` and `SegmentedControl`, plus the one-time install of every Radix primitive this phase needs.

Purpose: these are the rows the add/edit sheet (D-01, D-04) is made of, and the place where a credential could leak into the browser's password manager. Building the label/error/`aria-invalid` wiring once, inside `Field`, and proving it with a component test is what keeps per-field accessibility out of individual screens.
Output: four components, each with a colocated component test seen to fail first, and seven provenance-checked Radix packages.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser password manager → credential fields | Autofill offering to save an SSH key as a website login |
| pasted credential text → the DOM | A private key must exist in exactly one place in the document, never echoed into a second attribute |
| error text from the API → rendered field | The only permitted message source is the API's own `message` field |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-32 | Information Disclosure | credential inputs and browser autofill | mitigate | `Input`/`Textarea` forward `autoComplete` verbatim, asserted in a component test for both the `off` and the `current-password` case; the call sites enforce which value is used (Plans 05-11 and 05-17) |
| T-5-35 | Information Disclosure | error text rendered in a field | mitigate | `Field`'s error slot renders a caller-supplied string verbatim, asserted by a test that the rendered error equals the input string exactly — the client never composes from an exception |
| T-5-41 | Information Disclosure | a credential value duplicated into a second DOM attribute | mitigate | A component test types a distinctive string and asserts it appears in the control's `value` and nowhere else in the render |
| T-5-34 | Tampering | overridden Radix accessibility behaviour | mitigate | Grep gate asserting no `onKeyDown`/`tabIndex` in `SegmentedControl`; Plan 05-23 extends the gate to `onEscapeKeyDown`/`onInteractOutside` for the overlays |
| T-5-SC | Tampering | `pnpm add` of seven `@radix-ui/react-*` packages | mitigate | All seven in ADR-0000's Phase 5 additions table; provenance script re-run in Task 1's verify |
</threat_model>
