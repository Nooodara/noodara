    - `formatRelativeTime` of a timestamp 30 seconds before the reference clock is "just now"; 5 minutes before is "5 minutes ago"; 1 minute before is "1 minute ago" (singular); ~3 hours before is "3 hours ago"; ~2 days before is "2 days ago". The reference clock is an injected parameter, never `Date.now()` inside the function.
    - `formatRelativeTime(null)` returns a fixed dash-like placeholder, never "Invalid Date" and never an empty string.
    - `formatIso` returns the full ISO 8601 string for a valid input and the same placeholder for null.
    - `formatMb(2048)` renders as "2 GB"; `formatMb(512)` as "512 MB"; `formatMb(null)` as the placeholder. No value is silently rounded to zero.
    - `formatUptime(93784)` renders as "1 day, 2 hours" (largest two units, no seconds); `formatUptime(45)` as "45 seconds"; `formatUptime(null)` as the placeholder.
    - `formatDiskUsage(used, total)` returns both a human string ("18 GB of 40 GB") and a fraction between 0 and 1 for the meter; with either input null it returns the placeholder and a null fraction; with total 0 it does not divide by zero.

Use `Intl.NumberFormat`/`Intl.RelativeTimeFormat` where it removes hand-rolled pluralization, with the `en` locale pinned explicitly so output is deterministic in tests and independent of the runner's locale. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API-supplied strings (activity metadata, discovery `detail`, error messages) → rendered DOM | The XSS surface of the whole admin UI |
| clipboard API → OS clipboard | A copy affordance pointed at the wrong value would export sensitive data |
| `localStorage` → `data-theme` | Untrusted stored value reaches a DOM attribute |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-36 | Tampering | every display component | mitigate | Grep gate asserting zero `dangerouslySetInnerHTML` and zero `JSON.stringify` in `packages/ui/src`; React's default escaping is the control, and this gate is what keeps it |
| T-5-37 | Information Disclosure | `CopyButton` | mitigate | Doc comment restricting it to fingerprint, public URL and command strings; no component in this plan passes credential material to it, and `ServerView` structurally cannot carry one |
| T-5-38 | Tampering | `ThemeToggle` writing `data-theme` | mitigate | Only `light`/`dark`/absent are ever written; the attribute is a presentational hook with no security meaning; `localStorage` access is try/catch-guarded |
| T-5-39 | Information Disclosure | `Banner` rendering an error | mitigate | Message and `errorCode` are separate, caller-supplied props; no path renders an exception object |
| T-5-40 | Accessibility failure | state conveyed by colour or motion only | mitigate | Skeletons respect `prefers-reduced-motion`; no spinner exists (grep-gated); status words come from `STATUS_WORDS` in Plan 05-06 |
| T-5-SC | Tampering | npm installs | mitigate | No new packages: all Radix primitives were installed and provenance-checked in Plan 05-08 |
