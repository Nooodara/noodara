## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `GET /api/config` → rendered DOM | The one screen that shows security-adjacent configuration, including a key fingerprint |
| read-only screen → future edit affordance | A settings screen is the natural place for someone to later add a write path that the API does not support |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-69 | Information Disclosure | master key fingerprint row | mitigate | The API returns a truncated SHA-256 only, never key bytes; a component test and the E2E both assert no base64-looking 44-character string appears in the output |
| T-5-70 | Tampering | an edit affordance appearing later | mitigate | The row type has no editable/onChange field, and both a component test and the E2E assert zero input-like roles by role query rather than by tag-name grep — so a custom component behaving like an input is caught too |
| T-5-71 | Information Disclosure | timeouts and concurrency exposure | accept | Single-admin instance configuration the admin set themselves; D-16 explicitly includes them, captioned as environment-variable-sourced |
| T-5-72 | Information Disclosure | public URL copy button | accept | The public URL is public by definition; the copy affordance touches no credential |
| T-5-SC | Tampering | npm installs | mitigate | No new packages in this plan |
</threat_model>
