<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test fixture env → real application processes | A misconfigured origin/port pair would either hide a real `FORBIDDEN_ORIGIN` bug or fabricate one |
| test credentials → committed repository | Preseeded admin credentials live in test code and are scanned by gitleaks |
| Testcontainers → developer machine | Stray containers accumulate and (per STATE.md) this machine already suffers Docker resource contention |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-41 | Spoofing | E2E Origin/port configuration | mitigate | The fixture implements ADR-0006's contract explicitly (API 3100, web 3000, `NOODARA_PUBLIC_URL` = web origin) so the Origin guard is exercised honestly rather than bypassed |
| T-5-42 | Information Disclosure | preseeded admin credentials in test code | mitigate | Obviously-fake fixed values, documented as fixtures; gitleaks already runs on the tree and `.gitleaks.toml`'s allowlist is path-scoped — if it flags this file, add a path-scoped entry rather than a broad regex |
| T-5-43 | Denial of Service | stray containers / half-started stack | mitigate | `stopStack` guards each step and ends with `assertNoStrayTestContainers()`; `startStack` rejects with the failing process named rather than resolving half-started |
| T-5-44 | Repudiation | flaky E2E masking a real defect | mitigate | `retries: 0`, `forbidOnly` in CI, `workers: 1`; failure artifacts (trace, screenshot) retained |
| T-5-SC | Tampering | `pnpm add @playwright/test` plus browser binary download | mitigate | Package is in ADR-0000's Phase 5 additions table and re-checked by the provenance script; browser binaries come from Playwright's own installer, pinned by the package version |
</threat_model>
