## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated HTTP client → `POST /api/servers/:id/trust-fingerprint` | Any authenticated caller (a script, a compromised session, a stale tab that remembers the request shape) can reach this route directly; `pendingFingerprint` is returned unconditionally by `GET /api/servers/:id`, so the value is not secret |
| web UI's affordance gating → the actual trust decision | The UI hiding a button is not a control; the transaction is |
| `pending_fingerprint` (untrusted, observed) → `host_fingerprint` (trusted) | The TOFU promotion this route performs |
