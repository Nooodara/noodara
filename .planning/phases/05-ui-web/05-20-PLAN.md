## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| E2E fixture credentials → a real SSH container | A real private key and password authenticate against a real sshd during the test |
| CI workflow → the merge gate | A job that cannot fail provides false assurance |
| long-running nightly → developer machine resources | Testcontainers accumulation is an existing, documented problem on this machine |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-92 | Repudiation | a green E2E job that asserts nothing meaningful | mitigate | The spec asserts real discovered values and a mixed intermediate progress state; the placeholder comment in `ci.yml` is removed so no reader can believe E2E is still deferred |
| T-5-93 | Information Disclosure | test SSH keys and passwords in the repo and in CI logs | mitigate | Keys come from the existing `tests/integration/helpers/ssh.ts` fixtures (generated per run, not committed); no credential is echoed into a Playwright report assertion message |
| T-5-94 | Denial of Service | stray containers after a 20-iteration nightly | mitigate | Every job ends with the `noodara.test=true` stray-container check, and `stopStack` guards each teardown step |
| T-5-95 | Repudiation | nightly claimed as passing when it never runs | mitigate | A comment in the workflow and a blocking human checkpoint make the "no remote yet" limitation explicit rather than implied |
| T-5-96 | Information Disclosure | Playwright trace artifacts containing a credential | accept | Traces are uploaded only on failure and contain the fixture's per-run generated key, not a real secret; artifacts have a retention limit like the existing coverage upload |
| T-5-SC | Tampering | npm installs and Playwright browser download in CI | mitigate | `--frozen-lockfile` plus the provenance job added in Plan 05-03; browsers come from the pinned Playwright version's own installer |
</threat_model>
