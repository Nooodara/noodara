<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → control plane over the Next proxy | Every request crosses here; a hung peer is an availability threat |
| browser environment (clipboard, storage) → app code | Environment capabilities are not guaranteed on Noodara's plain-HTTP self-hosted target |
| runtime exception → rendered surface | An error boundary is a place raw internals can leak |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5G-28-01 | Denial of Service | `api-client.ts` `performRequest` | mitigate | `AbortSignal.timeout(API_REQUEST_TIMEOUT_MS)` on every request; abort maps to the existing bounded `NETWORK_ERROR` shape |
| T-5G-28-02 | Denial of Service | `CopyButton` / detail page on a non-secure origin or blocked storage | mitigate | Feature detection + `safeLocalStorage` + a `(shell)/error.tsx` boundary so no environment condition removes a screen |
| T-5G-28-03 | Information Disclosure | error boundary output | mitigate | Fixed English copy only; `error.message`/`stack`/`digest` never rendered — asserted by grep |
| T-5G-28-04 | Information Disclosure | abort/timeout error text | mitigate | The existing catch's rule (never echo the rejected error's own message) is extended to the abort case; no `AbortError` string reaches the UI |
| T-5G-28-05 | Information Disclosure | clipboard failure logging | mitigate | The empty catch stays empty; no `console.*` in either changed component |
| T-5-28-SC | Tampering | npm/pnpm installs | mitigate | NO new dependency. `AbortSignal.timeout`/`AbortSignal.any` are platform APIs. If an install seems necessary, stop and report. |
