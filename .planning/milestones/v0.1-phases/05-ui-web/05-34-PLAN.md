## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE client socket → control plane | A remote peer controls read rate and can go half-open; slots are a finite resource |
| exception → log sink | Errors carry arbitrary internal data that must stay inside redaction |
| process supervisor → worker entrypoint | A silent exit-0 death is indistinguishable from a clean shutdown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5G-34-01 | Denial of Service | `GET /api/events` subscriber slots | mitigate | Socket `'error'`/`'close'` teardown plus a bounded backpressure budget; integration test proves a fresh client can connect after leaked-then-recovered streams |
| T-5G-34-02 | Denial of Service | worker dying silently on a boot rejection | mitigate | Guarded `main()` with a non-zero exit so a supervisor restarts it; boot test asserts the exit code |
| T-5G-34-03 | Information Disclosure | new SSE teardown log lines | mitigate | Log only a connection identifier and a fixed reason — never the request URL/query, never a header; `pnpm security:scan-leaks` is the gate |
| T-5G-34-04 | Information Disclosure | `err` now emitted as structured fields | mitigate | pino's configured `err` serializer + redaction paths apply precisely because the error is under the `err` key; canary re-run confirms |
| T-5G-34-05 | Repudiation | errors flattened to a message, diagnosis lost | mitigate | `{ err }` merging-object form preserves type/stack |
