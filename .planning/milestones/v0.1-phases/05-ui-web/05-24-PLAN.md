<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| discovered fact strings (hostname, OS, versions) → rendered DOM | Values originating from a remote server the admin does not fully control |
| clipboard API → OS clipboard | A copy affordance pointed at the wrong value would export sensitive data |
| a point-in-time snapshot → a user reading it as live | Misrepresenting infrastructure state is a correctness and trust failure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-36 | Tampering | every display component | mitigate | Grep gate asserting zero `dangerouslySetInnerHTML` and zero `JSON.stringify` in `packages/ui/src` |
| T-5-37 | Information Disclosure | `CopyButton` | mitigate | Doc comment restricting it to fingerprint, public URL and command strings; a component test asserts `writeText` receives exactly the `value` prop and that nothing is logged on failure; `ServerView` structurally cannot carry a credential |
| T-5-61 | Spoofing | a snapshot read as a live metric | mitigate | `RelativeTime` always carries the exact instant in a `dateTime` attribute and `StatTile` always accepts an as-of caption; a null value renders the placeholder rather than a zero, asserted in a test |
| T-5-44 | Spoofing | stale facts presented as current | mitigate | `data-dimmed` makes DETL-02's attenuated treatment observable, so Plan 05-14's screen test and Plan 05-14's E2E can both assert it rather than trusting a colour |
| T-5-SC | Tampering | npm installs | mitigate | No new packages: all Radix primitives were installed and provenance-checked in Plan 05-08 |
