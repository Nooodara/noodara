    - `formatRelativeTime(null)` returns the shared placeholder, never "Invalid Date" and never an empty string.
    - `formatIso` returns the full ISO 8601 string for a valid input and the same placeholder for null.
    - `formatMb(2048)` renders as "2 GB"; `formatMb(512)` as "512 MB"; `formatMb(null)` as the placeholder. No value is silently rounded to zero.
    - `formatUptime(93784)` renders as "1 day, 2 hours" (largest two units, no seconds); `formatUptime(45)` as "45 seconds"; `formatUptime(null)` as the placeholder.
    - `formatDiskUsage(used, total)` returns both a human string ("18 GB of 40 GB") and a fraction between 0 and 1 for the meter; with either input null it returns the placeholder and a null fraction; with total 0 it does not divide by zero and the fraction is null, not NaN.

| Boundary | Description |
|----------|-------------|
| API-supplied strings (error messages, codes) → rendered DOM | The XSS surface of every failure state in the admin UI |
| exception object → rendered banner | The one place a stack trace or payload could be shown to a user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-36 | Tampering | every display component | mitigate | Grep gate asserting zero `dangerouslySetInnerHTML` and zero `JSON.stringify` in `packages/ui/src`; React's default escaping is the control, and this gate is what keeps it |
| T-5-39 | Information Disclosure | `Banner` rendering an error | mitigate | Message and `errorCode` are separate, caller-supplied props; a component test asserts the rendered message equals the input exactly, so a composed-from-exception implementation fails |
| T-5-40 | Accessibility failure | state conveyed by colour or motion only | mitigate | Skeletons respect `prefers-reduced-motion`; no spinner exists, asserted in a component test as well as grep-gated; status words come from `STATUS_WORDS` in Plan 05-22 |
| T-5-43 | Spoofing | two competing actions in one empty state | mitigate | The action prop is typed as a single optional object, verified by a `@ts-expect-error` case in the test file plus a runtime button-count assertion |
| T-5-SC | Tampering | npm installs | mitigate | No new packages: all Radix primitives were installed and provenance-checked in Plan 05-08 |
