<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `POST /api/servers/:id/trust-fingerprint` | Untrusted body crossing into a trust-establishing action |
| control plane → `servers.host_fingerprint` | The stored TOFU anchor used for every future SSH connect |
| concurrent connect worker → `servers.pending_fingerprint` | A second connect attempt can rewrite the pending value mid-review |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5G-27-01 | Spoofing | trust route / `trustFingerprint` | mitigate | Required `{ fingerprint }` body + atomic `WHERE pending_fingerprint = $1` conditional UPDATE; mismatch → 409, nothing promoted. Closes the display-vs-promote TOCTOU the 05-19 client-side re-GET could only narrow. |
| T-5G-27-02 | Tampering | `servers.host_fingerprint` | mitigate | Promotion happens in one conditional statement inside the existing row-locked transaction; the concurrency integration test asserts a mid-flight flip promotes nothing |
| T-5G-27-03 | Spoofing | identity edit leaving a stale pending fingerprint | mitigate | `identityChanged` clears both pending columns for every status (WR-A-02); regression test covers a non-ERROR status |
| T-5G-27-04 | Denial of Service | `InvalidTransitionError` → 500 on a legitimate request | mitigate | `canTrustFingerprint` guard returns a typed 409 `SERVER_NOT_TRUSTABLE` before `transition` is reached |
| T-5G-27-05 | Information Disclosure | error bodies as an oracle | accept | Fingerprints are public identifiers already exposed by `GET /api/servers/:id` (D-16); messages are kept generic and symmetric anyway |
| T-5G-27-06 | Repudiation | trust decisions not attributable | mitigate | Existing `server.fingerprint_trusted` activity event retains actor + `{ previousFingerprint, newFingerprint }`; the mismatch branch writes no event (nothing happened) |
| T-5-27-SC | Tampering | npm/pnpm installs | mitigate | NO new dependency. `and` comes from the already-installed `drizzle-orm`. If an install seems necessary, stop and report. |
</threat_model>
