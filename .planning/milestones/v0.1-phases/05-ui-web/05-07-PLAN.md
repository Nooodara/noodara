<interfaces>
The API error vocabulary the client must parse (from `apps/control-plane/src/routes/http-errors.ts`, verified 2026-09-19):

Plain failure body: `{ error: ServiceErrorCode, message: string }`.
Validation failure body: `{ error: 'VALIDATION_FAILED', message: string, issues: { path: string, message: string }[] }`.
`ServiceErrorCode` is one of: `VALIDATION_FAILED`, `INVALID_CREDENTIAL`, `UNAUTHORIZED`, `FORBIDDEN_ORIGIN`, `NOT_FOUND`, `NAME_TAKEN`, `HOST_TAKEN`, `SERVER_BUSY`, `ALREADY_CONNECTING`, `SERVER_NOT_CONNECTED`, `NO_PENDING_FINGERPRINT`, `CONFIRMATION_MISMATCH`, `QUEUE_UNAVAILABLE`, `SSE_LIMIT_REACHED`, `INTERNAL_ERROR`.
`503 SSE_LIMIT_REACHED` and `QUEUE_UNAVAILABLE` carry a `Retry-After` header.
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → `apps/web` → Fastify API | The proxy is the only path between the browser and the control plane; a cross-origin target here would break the Origin guard's assumption |
| API error body → rendered UI | An unparsed or echoed error body is the classic path for leaking internals into a page |
| `localStorage` → `<html data-theme>` | Untrusted stored value reaches a DOM attribute before hydration |
| third-party page → framed admin UI | Clickjacking a single-admin control plane |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-5-26 | Tampering | `api-client.ts` request target | mitigate | Relative-`/api/`-only assertion plus `credentials: 'same-origin'`; an absolute URL throws before any fetch, so `FORBIDDEN_ORIGIN` cannot be bypassed from client code |
| T-5-27 | Information Disclosure | error rendering | mitigate | Only the API's own `message` is surfaced; a non-JSON body degrades to a fixed generic message; no `console.*` and no request-body stringification in the client |
| T-5-28 | Tampering | clickjacking of the admin UI | mitigate | `X-Frame-Options: DENY` plus CSP `frame-ancestors 'none'` in `next.config.ts` headers (new item, not covered by Phase 4) |
| T-5-29 | Tampering | theme bootstrap `dangerouslySetInnerHTML` | mitigate | The injected string is a module constant with zero interpolation; it is the single reviewed occurrence repo-wide and Plan 05-21 enforces the count with a grep gate |
| T-5-30 | Denial of Service | missing `NOODARA_API_ORIGIN` at boot | mitigate | Fail fast with an error naming the variable (no silent literal fallback, which eslint bans anyway); the variable is declared in `passThroughEnv` and `.env.example` |
| T-5-SC | Tampering | `pnpm add` of next, tailwindcss, @tailwindcss/postcss | mitigate | All present in ADR-0000's Phase 5 additions table; `node scripts/check-package-provenance.mjs` re-run as part of Task 1's verify |
</threat_model>
