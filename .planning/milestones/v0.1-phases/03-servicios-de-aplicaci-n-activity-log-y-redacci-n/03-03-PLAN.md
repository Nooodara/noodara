## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application service -> Postgres | Uniqueness and referential rules must hold at the database, not only in service code, so a bypassed check cannot corrupt state |
| discovery result -> discovery_snapshots.payload | Untrusted remote command output crosses into persisted jsonb |

## STRIDE Threat Register

| Threat ID | Category | Description | Asset | Severity | Disposition | Mitigation (task) |
|---|---|---|---|---|---|---|
| T-3-13 | Tampering | Two servers registered with names differing only by case, or with the same host:port, produce ambiguous identity and racing connects | `servers` identity | high | mitigate | Task 2's `lower(name)` and `(host, ssh_port)` unique indexes, proven by Task 1's 23505 behaviour cases |
| T-3-11 | Information Disclosure | Discovery snapshots of a deleted server survive and keep exposing host facts | `discovery_snapshots` rows | medium | mitigate | Task 2's FK `ON DELETE CASCADE` (D-08), proven by Task 1's cascade case |
