## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| service call site -> activity_events | Metadata composed by a service crosses into persisted audit data; a forbidden key or a SecretValue must fail loudly rather than be laundered |
| discovery result -> servers row | Partial/failed facts cross into denormalized columns other views will read as truth |

## STRIDE Threat Register

| Threat ID | Category | Description | Asset | Severity | Disposition | Mitigation (task) |
|---|---|---|---|---|---|---|
| T-3-02 | Information Disclosure | A `server.*` event carries credential material in metadata | `activity_events.metadata` | high | mitigate | Task 3 keeps `assertNoSensitiveMetadata`/`SensitiveMetadataError` in force for the widened union and adds an explicit test that a `server.created` event with a `credential` key throws; value-based redaction is proven end-to-end by plan 03-10's canary |
| T-3-17 | Tampering | Stale facts survive a failed discovery and are reported as current | `servers` denormalized columns | medium | mitigate | Task 1's null-never-overwrites rule (D-07) with a per-key exhaustive test; snapshot `outcome` classification keeps the failure visible |
| T-3-18 | Tampering | An unknown/free-form action string is persisted, breaking the typed audit trail | `activity_events.action` | medium | mitigate | Task 3's runtime membership check over the combined set, asserted for both an unknown `server.*` and an unknown namespace |
