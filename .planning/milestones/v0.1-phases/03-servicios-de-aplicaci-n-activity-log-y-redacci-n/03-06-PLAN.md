<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| concurrent connect job -> edited row | An in-flight `connectAndDiscover` must not write status or fingerprint onto a row being edited |
| edit input -> credentials row | Replacement material crosses into storage; the previous material must never cross back out |

## STRIDE Threat Register

| Threat ID | Category | Description | Asset | Severity | Disposition | Mitigation (task) |
|---|---|---|---|---|---|---|
| T-3-06 | Tampering | An edit lands while a connect job is in flight, producing a fingerprint or status belonging to the old host | `servers.status`, `host_fingerprint` | high | mitigate | Task 2's `SELECT ... FOR UPDATE` plus the D-11 `SERVER_BUSY` rejection; asserted by the "row byte-identical after SERVER_BUSY" case |
| T-3-26 | Information Disclosure | The existing credential is read back (to "prefill" or "compare") and leaks into a result or log | `credentials.encrypted_value` | high | mitigate | Task 2 never selects or decodes the existing credential; enforced by the grep criterion and by the result-JSON assertion |
| T-3-27 | Spoofing | Host/port change keeps the old pinned fingerprint, so a different machine inherits trust | `servers.host_fingerprint` | high | mitigate | Task 2 clears `host_fingerprint`/`host_fingerprint_captured_at` on an identity change, restoring TOFU for the new target; asserted directly against the row |
| T-3-12 | Tampering | A status literal is assigned, bypassing the state machine | `servers.status` | high | mitigate | The `grep -c "status: '"` == 0 criterion plus exclusive use of `transition()` |
| T-3-02 | Information Disclosure | `server.updated` metadata carries old/new host or user values, building a host history in the audit log | `activity_events.metadata` | medium | mitigate | D-16's changedFields-only metadata, asserted deep-equal |
| T-3-13 | Tampering | An edit creates a duplicate identity that registration would have rejected | `servers` identity | high | mitigate | Self-excluding uniqueness pre-checks + 23505 translation over plan 03-03's indexes |
</threat_model>
