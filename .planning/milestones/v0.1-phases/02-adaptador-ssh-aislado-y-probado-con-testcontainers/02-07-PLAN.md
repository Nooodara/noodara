<objective>
Make failure a first-class, exhaustively-tested value: one classification table from ssh2's real error shapes to the seven error codes, and one timeout wrapper that no command can escape.

Purpose: SERV-07's actual requirement is "la API nunca cae" — the guarantee is not that errors are handled somewhere, it is that no ssh2 error shape has an unhandled path. That is only provable with a table that is exhaustive over a closed union and a fallback that is a deliberate decision rather than a gap. `ssh2` has no native per-exec timeout, so SEC-04's "cada comando tiene timeout explícito" is entirely this plan's `Promise.race` wrapper, and SEC-05's redaction is the same wrapper's last step.
Output: `errors.ts`, `error-classifier.ts` with a table-driven exhaustive test, and `exec-with-timeout.ts` with fake-timer tests.
</objective>

    `exec-with-timeout.ts` exports `MAX_OUTPUT_BYTES = 65_536` and `execWithTimeout(input)` where `input` is `{ client, commandName, timeoutMs, redactor }`. Type `client` as the narrowest structural interface the function actually needs — `{ exec(command: string, cb: (err: Error | undefined, channel: ExecChannel) => void): void }` with a local `ExecChannel` interface covering `on('data')`, `stderr.on('data')`, `on('close')` and `destroy()`. A structural type is what makes the fake-channel unit tests honest rather than a mock of a mock, and it keeps `ssh2`'s concrete `Client` out of this module's signature.

    This is the one module in the phase where a fake is the right test double: the behaviour under test is timer and stream mechanics, and 02-RESEARCH.md's "no mocked ssh2.Client for connection-outcome scenarios" rule is about connection outcomes, which plans 02-08 and 02-10 cover against real containers. State that reasoning in a comment at the top of the test file so a reviewer does not read it as a shortcut.

    Accumulate stdout and stderr as `Buffer` chunks with a running byte count, stop appending once the limit is reached, and decode once at the end with `toString('utf8')` on the truncated buffer — that is what makes truncation byte-exact and multi-byte-safe in one step, instead of concatenating strings and slicing afterwards.

    Measure `durationMs` from a monotonic source (`performance.now()`), not `Date.now()` — a wall-clock adjustment mid-command must not produce a negative or absurd duration in the `DiscoveryCheck` this value feeds.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Remote command output → logs, activity events, API responses, UI | stdout and stderr are produced on a machine Noodara does not control and may echo a credential the command was given |
| ssh2 error object → control-plane error handling | An unhandled error shape becomes an unhandled rejection in the worker that runs this adapter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2-26 | Denial of Service | Unclassified ssh2 error escaping as an unhandled rejection | mitigate | An ordered rule table with an explicit terminal fallback, exhaustive over `SERVER_ERROR_CODES`; `classifySshError` contains no `throw` and is tested against hostile inputs including a throwing `message` getter (SERV-07) |
| T-2-27 | Denial of Service | A command that never returns | mitigate | Every exec is raced against a timer that destroys the channel and settles once; the timer is cleared on all three exit paths and no test leaves a pending timer (SEC-04, D-08) |
| T-2-28 | Information Disclosure | Credential echoed in command stdout/stderr | mitigate | `Redactor.redact` applied to both streams before an `ExecResult` exists, with a test that emits a registered secret and asserts the marker (SEC-05) |
| T-2-29 | Denial of Service | Unbounded output exhausting memory or log volume | mitigate | 64 KB per stream, counted in bytes with buffer-level truncation, `truncated` surfaced on the result so a caller knows the output is partial |
| T-2-30 | Information Disclosure | Raw ssh2 message reaching an operator-facing error | mitigate | Classifier messages are project-authored and additionally passed through `redact`; a test asserts no message changes under a redactor holding the credential |
</threat_model>
